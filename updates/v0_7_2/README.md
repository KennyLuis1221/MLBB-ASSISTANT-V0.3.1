# V0.7.2 — modo sem assinatura
Gemini 3.5 Flash-Lite via projeto Free Tier sem billing. Nenhuma chave no APK. Configurar GEMINI_API_KEY somente no Render, MLBB_FREE_PROJECT_CONFIRMED=1 apenas após verificar Free Tier, MLBB_VISION_ENABLED=1, MLBB_PUBLIC_SESSION_ENABLED=1. Quota local de 10 chamadas/dia (máximo 20) em memória, não é garantia de cobrança zero se o projeto for pago; sem billing no Google, sem fallback pago. A cota pode reiniciar em reinicializações do Render. O Google pode usar dados do plano gratuito para melhorar produtos. Use imagens de treino sem informações pessoais. Provedor não testado ao vivo sem chave. 12 planos individuais experimentais e fallback de classe para demais; não validados por patch. Draft melhora exclusões, favoritos e hipóteses de habilidades no servidor; não há counters completos. Teste real ainda depende de captura de draft/placar durante partida.
